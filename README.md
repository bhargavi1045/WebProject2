# 📬 Simple Contact Form

This is a minimal contact form built with **HTML**, **CSS**, and **JavaScript**. It allows users to submit their name, email, and message — perfect for portfolios, small business sites, or any personal web project.

---

## ✨ Features

- 📝 Input fields for name, email, and message  
- ✅ Basic form validation using JavaScript   
- 🎨 Clean and accessible UI  

---

## 🛠️ Tech Stack

| Part      | Technology   |
|-----------|--------------|
| Structure | HTML5        |
| Styling   | CSS3         |
| Logic     | JavaScript   |
